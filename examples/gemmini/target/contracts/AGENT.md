# Public capability inputs

The contract and residual are human-authored prototype inputs, not generated or
certified results. Their parsed YAML currently has the same content; do not treat
them as independent evidence or let edits drift. The selected contract path is
stable for discovery and existing experiment definitions. A future derived
contract belongs in a content-identified output artifact, not beside these
authored sources. Executable plugin declarations belong to the selected OOT
support provider, not these example inputs.
Qualified RTL facts remain explicit external artifacts; never invent missing facts
or copy private support here to satisfy tests.
