# TVM–Gemmini comparison

This directory owns model recipes, independent numerical references, input preparation and session verification for the pinned TVM–Gemmini baseline. TVM owns ONNX import, Relax graph optimization, integer decomposition, Gemmini primitive schedules, bounded learned search and static export. [HOST_SETUP.md](HOST_SETUP.md) contains build and workload commands; the [TVM integration guide](../../../../third_party/baselines/tvm-gemmini/apps/gemmini/README.md) describes the backend.

Torch models export through ONNX to Relax. [verify_resnet.py](verify_resnet.py) checks complete image streams; [verify_session.py](verify_session.py) compiles static stage signatures, independently routes Torch/TVM state and checks every output, repeat and reset. Explicit model recipes select checkpoint conversion, quantization and CPU operations. Reports bind selected sources, checkpoints, inputs, compiler library, graphs and numerical gates; hashes do not establish complete runtime source closure.

## Compiler and target contract

[target.yaml](target.yaml) records the independent TVM source pin, provisional pre-MX integer Gemmini sources, baremetal RV64GC/lp64d, primitive-only output-stationary calls and a hypothetical 8-GiB memory map. Merlin does not track TVM as a submodule. YAML paths use the Merlin checkout as their base; environment references are declarations, not automatically expanded values. The [existing descriptor](../../target/descriptor.yaml) is reference material and does not qualify these selections.

The device arithmetic boundary is dense row-major signed INT8 operands and INT32 results, with positive static shapes and K≤131071. Generic linear lowering flattens left leading dimensions against shared rank-two weights; convolution uses explicit CPU packing/restoration. Bias, activation, scales, attention and state handling stay where each recipe declares them. TVM composes Gemmini C-library primitives in compiler-owned schedules; WS/FSM paths are prohibited. The whole-matmul C adapter is a separately checked reference path, with one-array reduction tiles protecting the provisional 20-bit PE output and INT32 outer accumulation. The library CPU branch cannot supply a full-accumulator reference; independent bounded int64 oracles check integer arithmetic.

The provisional source set is Gemmini `6ad65b90`, gemmini-rocc-tests `7c540b3a` and libgemmini `ea8f7ed7`; the integer parameter header SHA256 is `3758ae967af3a179497660970201093a7fb624be00173990ce33d3f5c38da924` (16×16 geometry, 256-KiB scratchpad, 64-KiB accumulator). Build verification stages exact Git blobs and checks resolved includes. The live floating-point header is incompatible. Hardware identity, usable guest DRAM and deployed completion/coherence remain unconfirmed.

Graph optimization preserves the device boundary while folding constants and fusing surrounding CPU operations. Search uses TVM features/XGBoost and finite, candidate-bound measurement requests; synthetic labels check machinery only. Shared-stage export deduplicates constants, reuses serial workspace and rejects hidden runtime allocators. After host gates pass, the session verifier derives typed routes and original-source fixtures and accounts for simultaneously live state/output buffers. This adapter passes a bounded automatic INT8 session on matched Spike. ELF, stack, runtime/platform reservations and retained verification fixtures have separate budgets; complete-model numerical/device qualification and deployed memory fit remain. CPU math libraries must be bound explicitly.

Use [target checks](HOST_SETUP.md#provisional-target-checks), [functional simulator checks](HOST_SETUP.md#pinned-functional-simulator) and [graph/search checks](HOST_SETUP.md#scheduled-graph-and-learned-search-checks) for the respective boundaries. Keep TRAIN/calibration, development and held-out data separate, freeze recipes before final evaluation and preserve unchanged numerical gates. Captures, weights, binaries and receipts belong under configured `out/` roots. Deployment and timing approval remain separate.
